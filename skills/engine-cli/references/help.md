# Engine CLI help command reference

All commands inherit the root flags documented in [SKILL.md](../SKILL.md).

## `engine-cli help`

Help about any command

Usage: `engine-cli help [command] [flags]`.

Help provides help for any command in the application.
Simply type engine-cli help [path to command] for full details.

- `--help, -h` (bool; default `false`): help for help.
